## 📌 Overview

**SurakshaAI** is a modern web-based disaster management dashboard designed to help authorities, NGOs, rescue teams, and communities respond faster during natural disasters such as floods, cyclones, earthquakes, and humanitarian emergencies.

The platform combines:

* 📡 Real-time social signal monitoring
* 🤖 AI-powered alert verification
* 🗺️ Interactive live resource maps
* 🚑 Emergency supply coordination
* 🌍 Eco-friendly relief operations

Built with a visually rich UI using **HTML, CSS, JavaScript**, and **Leaflet.js**, the dashboard focuses on both speed and sustainability.

---

## ✨ Key Features

### 🚨 Real-Time Disaster Monitoring

Continuously tracks emergency-related reports and field updates.

### 🤖 AI Verified Alerts

Uses intelligent filtering logic to classify reports as:

* ✅ Verified
* ⚠️ Pending
* 🚨 Critical

### 🗺️ Interactive Relief Map

Live map powered by **Leaflet.js** showing:

* Shelter camps
* Food aid hubs
* Water rescue points
* Medical zones
* High-risk alerts

### 📊 Animated Statistics Dashboard

Displays live counters for:

* Posts scanned
* Verified alerts
* Resources mapped
* Accuracy rate

### 🌿 Eco-Friendly Operations

Promotes sustainable emergency management:

* Low-emission rescue routes
* Solar-powered medical units
* Reusable food containers
* Portable clean-water refill hubs

### 🎨 Premium Modern UI

Includes:

* Glassmorphism design
* Responsive layout
* Gradient aesthetics
* Smooth animations
* Mobile-friendly interface
